### Conflicts and narrow resolutions

1. **Old task-trigger discrepancy:** October Domsky source notes conflicted. Current C06 pages agree on ordinary Classic Zap triggers. Keep the existing page unchanged in this draft task; flag an owner-approved maintenance update separately. Do not repeat a stale conflict as if just verified.
2. **Migration marketing vs Help:** marketing describes recreating an agent; Help describes automatic conversion of its existing bundle. Cite Help for setup details; the article need only describe the current architectural option, not promise an account migration path.
3. **Defaults and tool eligibility:** marketing wording about free/default AI is too broad for a deployed tool-using flow. Current C07 specifies plan/model constraints. Use C07 for this boundary.
4. **Test billing:** migration Help contains an older note that full-Zap tests consume tasks; newer task Help excludes editor tests. No counters were observed. Testers must save before/after usage and identify the exact product/plan/test mode; the article must not promise free trial execution.
5. **Upcoming rates:** current rates include dated future/promo changes, including a 1 Dec 2026 Next Gen/SDK boundary and a 5 Jan 2027 MCP promotion end. Those surfaces are outside the proposed Classic-Zap comparison. A temporary rate is not a 2027 budget assumption. Recheck at implementation and release.
